CHAPTER 00

Web制作を始める準備

Webサイトを作るために必要な知識と道具をそろえましょう。 この章では、パソコンの基本から始めて、初めてのHTMLファイルを ブラウザで表示するところまで進みます。

📘 対象：プログラミング未経験者 ⏱ 目安：約60〜90分 💻 パソコンを使用

この章のゴール

章を終えるころには、次のことができるようになります。

  • Webサイトがブラウザに表示される大まかな仕組みを説明できる
  • ファイル・フォルダ・拡張子の違いが分かる
  • HTMLファイルを自分で作成できる
  • Visual Studio Codeでファイルを編集できる
  • 作成したHTMLファイルをブラウザで表示できる
  • GitHubが何のためのサービスか説明できる

Webサイトを作る人は何をする？

Webサイトを作るときは、HTMLやCSS、JavaScriptなどを使って ファイルを作成します。 それらのファイルをブラウザが読み込むことで、 文字や画像、ボタンなどが画面に表示されます。

2

ファイルとフォルダを理解しよう

パソコンで作業するとき、データは主に「ファイル」と「フォルダ」で管理します。 これはWeb制作に限らず、パソコンを使ううえで基本となる考え方です。

📄

ファイル

文章、画像、プログラムなど、データそのもの。

  • メモ.txt
  • 写真.png
  • index.html
📁

フォルダ

ファイルや別のフォルダをまとめて整理する入れ物。

  • 写真フォルダ
  • 学校の課題
  • websiteフォルダ

フォルダの中にフォルダを作れる

フォルダの中に別のフォルダやファイルを入れることができます。 Webサイトの制作でも、関連するファイルを一つのフォルダにまとめて管理します。

Webサイトのファイル構成例

📁 my-website
📄 index.html
📁 css
📄 style.css
📁 js
📄 script.js
📁 images
🖼️ logo.png

一つのWebサイトに関係するファイルを、my-websiteフォルダにまとめています。

実際にフォルダを作ってみよう

  1. デスクトップを表示する

    Windowsならデスクトップの何もない場所を、Macならデスクトップを表示します。

  2. 新しいフォルダを作る

    Windowsでは右クリックして「新規作成」→「フォルダー」、 Macでは右クリックして「新規フォルダ」を選びます。

  3. フォルダ名を付ける

    my-website という名前にしてください。半角英数字とハイフンを使います。

ファイルの保存場所を覚えておこう

作成したファイルがどこに保存されたか分からなくなると、 後で開けなくなってしまいます。 今回作るファイルは、必ず my-website フォルダの中に保存しましょう。

3

拡張子とは何だろう？

ファイル名の最後に付いている「.html」や「.png」などの部分を 拡張子といいます。 拡張子を見ると、そのファイルがどのような種類のデータなのか判断できます。

ファイル名の例

index.html

「index」がファイル名、「.html」が拡張子です。

よく使う拡張子

拡張子ファイルの種類用途
.htmlHTMLファイルWebページの構造を書く
.cssCSSファイルWebページの見た目を整える
.jsJavaScriptファイルWebページに動きをつける
.png画像ファイル画像を保存する
.jpg画像ファイル写真などを保存する
.txtテキストファイル文字だけの情報を保存する

Windowsで拡張子を表示する

Windowsでは、初期設定によって拡張子が表示されていない場合があります。 ファイル名が index だけに見えていても、 実際には index.html かもしれません。

  1. エクスプローラーを開く

    フォルダやファイルを表示するアプリです。

  2. 「表示」を選ぶ

    ウィンドウ上部にある「表示」メニューを開きます。

  3. 「ファイル名拡張子」をオンにする

    拡張子が表示されるようになります。Windowsのバージョンによって表示位置は多少異なります。

注意：index.html.txt にしない

拡張子を表示しないままファイル名を変更すると、 意図せず index.html.txt になることがあります。 HTMLファイルを作るときは、最後が本当に .html になっているか確認してください。

4

初めてのHTMLファイルを作ろう

ここから実際にファイルを作ります。 まずはHTMLファイルを一つ用意しましょう。 HTMLの詳しい書き方は第1章で学ぶため、 今はファイルを作成して表示することが目標です。

HTMLファイルを作成する

  1. my-websiteフォルダを開く

    先ほど作成したフォルダを開きます。

  2. 新しいファイルを作る

    後の節で導入するVisual Studio Codeを使って作成します。

  3. ファイル名を index.html にする

    必ず最後が .html になっていることを確認します。

次のコードを入力してみよう

次のコードをコピーするか、自分で入力してみてください。 このコードは、ブラウザに「はじめてのWebページ」と文章を表示するためのものです。

index.html 
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>はじめてのWebページ</title>
</head>
<body>
    <h1>はじめてのWebページ</h1>
    <p>HTMLの学習を始めました！</p>
</body>
</html>
コードの意味は今は全部分からなくても大丈夫

この段階では、コードを正しく保存してブラウザに表示できれば十分です。 <h1> や <p> の意味は第1章で詳しく説明します。

ファイルを保存する

ファイルを編集したら保存します。 保存先は、先ほど作った my-website フォルダです。

WindowsCtrl+S MacCommand+S

保存操作を忘れると、ブラウザで開いたときに古い内容が表示されることがあります。

作成したフォルダをVS Codeで開く

  1. VS Codeの「ファイル」メニューを開く

    画面上部のメニューから「フォルダーを開く」を選択します。

  2. my-websiteフォルダを選択する

    先ほど作成したフォルダを選びます。

6

ブラウザでHTMLを表示しよう

HTMLファイルを作成できたら、ブラウザで表示してみましょう。 Webサイトを公開する前でも、自分のパソコン上で表示を確認できます。

方法：HTMLファイルを直接開く

  1. my-websiteフォルダを開く

    エクスプローラー（Windows）またはFinder（Mac）でフォルダを表示します。

  2. index.htmlを探す

    先ほど作成したHTMLファイルを見つけます。

  3. index.htmlをダブルクリックする

    通常は既定のブラウザでファイルが開きます。

  4. 文章が表示されているか確認する

    「はじめてのWebページ」と「HTMLの学習を始めました！」が表示されていれば成功です。

index.html

はじめてのWebページ

HTMLの学習を始めました！

🎉
表示できたら成功です！

自分で作成したHTMLファイルを、ブラウザに表示できました。

表示がうまくいかないとき

ファイルを開いてもコードが表示される

ブラウザではなく、テキストエディタで開いている可能性があります。index.htmlを右クリックし、「プログラムから開く」などからブラウザを選んでください。

ファイル名が index.html.txt になっている

拡張子が二重になっています。ファイル名を確認し、最後が .html になるように変更してください。

変更した内容がブラウザに反映されない

VS Codeでファイルを保存してから、ブラウザを再読み込みしてください。

文字が正しく表示されない

HTMLの文字コード指定がUTF-8になっているか確認してください。今回のコードには <meta charset="UTF-8"> が含まれています。

7

GitHubを準備しよう

Webサイトを作るときは、自分のパソコンだけでファイルを管理することもできます。 しかし、インターネット上に保存したり、他の人と共有したりできると便利です。 そこで利用するのがGitHubです。

☁️

オンラインで保存

作成したプログラムをインターネット上に保管できます。

🕘

変更履歴を管理

いつ、どのような変更をしたか記録できます。

🌍

Webサイトを公開

GitHub Pagesを使ってWebサイトを公開できます。

🐙
GitHub 公式サイト

アカウントの作成はこちらから行います。

GitHubを開く ↗

アカウントを作成する

  1. GitHub公式サイトを開く

    上のリンクからGitHubにアクセスします。

  2. Sign upを選ぶ

    新しいアカウントを作成する画面に進みます。

  3. メールアドレスなどを登録する

    画面の案内に従って必要な情報を入力します。

  4. メールアドレスを確認する

    GitHubから届く案内に従い、登録を完了します。

ユーザー名は公開されることがあります

GitHubのユーザー名は、公開したWebサイトのURLなどに使われる場合があります。 本名や誕生日など、公開したくない個人情報を含めない名前を選ぶことをおすすめします。 パスワードや認証コードは他人に教えないでください。

GitHubとGitHub Pagesの違い

🐙

GitHub

プログラムのファイルや変更履歴を管理・共有するサービスです。

🌐

GitHub Pages

GitHubに保存したHTMLなどのファイルを、Webサイトとして公開する機能です。

この教材もGitHub Pagesを利用して公開することを想定しています。 実際に自分のWebサイトを公開する手順は、制作したページができてから取り組みます。 今はアカウントを準備できれば十分です。

GitHubを使うのは、今すぐでなくても大丈夫

HTMLファイルを作ってブラウザで表示するだけなら、GitHubのアカウントは必要ありません。 まずは自分のパソコンでWebページを作れるようになり、その後に公開方法を学びましょう。
